# V43 / V44：短いリテラルを連続処理する比較

2026-11-05作成・実機比較完了。**同じ画像列で完走し、平均フレーム時間を約6％短縮した。**

V41/V42は実機で同じ30フレームを完走した。V41では木の準備が約95 ms、
展開本体が約382 ms／フレームで、展開本体が粗い2区間合計の約80％だった。
V42の細かい標本は計測負担が大きいため、関数別占有率には使わない。
今回は詳細計測を外し、展開本体での関数呼出し・状態書戻しを減らす。

## 2本の差

- **V43：比較用。** V39のデコーダーを維持。コンパイル済み解凍オブジェクトも
  V39とバイト単位で同一。
- **V44：改良候補。** 7ビット検索表で確定するリテラル（値0〜255）を連続処理し、
  入力位置・ビット状態・出力位置をその間ローカル変数に保持する。
  長い符号、長さ／距離のコピー、ブロック終端、エラーは従来の有界デコーダーへ戻す。
  次の入力バイトは参照だけなら消費せず、storedブロックとの境界も維持する。
- 両版ともV41/V42の位相・ヘルパー計測、旧ページ順位・キャッシュカウンターの
  レジスター読取り、起動時クロック設定のスナップショットを省略。
  既存のフレーム・展開・送信の外側タイマーだけを残す。

ゲームパックはV37/V39と同じ1,249,137 B。2 KiBページ35枚、フラット8枚・カラム32本の
キャッシュ、120×120の8ビット画面と240×240への拡大・DMA送信は共通。
CPU／PLL／SFC、LCD分周値、Flash配置の方式は変えていない。両版とも解凍コードはFlash実行。
ネイティブのオブジェクト差は版表示を含む `bsp_platform.c.o` と `tinflate.c.o` のみ。

## 実機での比較

1. **V43 → V44** の順に書き込み、各版を通常起動。ボタンを押さずに待つ。
2. 10フレーム準備＋30フレーム測定の後、3行目が `0000D00E` になる。
3. 今回は左上の **全14行** を撮影する。V41/V42の30行表示とは異なる。

| 行 | 意味 | V43 | V44 |
|---|---|---|---|
| 1 | 版（16進） | `0000002B` | `0000002C` |
| 2 | 測定フレーム数 | `0000001E` | `0000001E` |
| 3 | 完了 | `0000D00E` | `0000D00E` |
| 4〜6 | フレーム全体：平均／最短／最長（ms） | 666／639／733 | 626／601／642 |
| 7〜9 | 展開区間：平均／最短／最長（ms） | 430／399／490 | 387／361／461 |
| 10〜12 | 送信区間：平均／最短／最長（ms） | 83／83／84 | 83／83／84 |
| 13 | 最終tic | `00000028`を確認 | `00000028`を確認 |
| 14 | 画像列ハッシュ | `C269CBCE`を確認 | `C269CBCE`を確認 |

入力無効・最後に止まるのはこの比較版の仕様。通常プレイの基準版はV30を維持する。
値は全て16進数。同じtic・画像列が一致してからフレーム／展開時間を比較する。
V41/V42は計測負担が異なるので、速度差の基準にはせずV43/V44を対にする。
開始地点のみの固定tic試験は通常プレイ全般のFPSや長時間安定性を保証しない。

## 実機結果：2026-11-05

ユーザー提供の両最終画面で、版 `2B`／`2C`・30測定フレーム・D00E・
最終40 tic・画像列ハッシュ `C269CBCE` が一致した。
平均フレーム時間は666→626 ms、40 ms（約6.01％）短縮。
展開時間は430→387 ms、43 ms（10.0％）短縮し、送信は83 msのまま。
今回の短いリテラル連続処理は、実測上残す価値がある。

ただし各版1回の固定tic開始地点での比較で、再現性や通常プレイ全般を保証しない。
バイナリー配置の変化もあり、短縮の全てを関数呼出し削減だけに分離して帰属させない。
平均時間の逆数は約1.50→1.60フレーム／秒で、まだプレイ可能な速度への突破ではない。
これは固定tic試験の参考換算であり、通常プレイの平均FPSとは区別する。
通常操作・移動中・長時間動作はこの2版では未確認。通常プレイ基準はV30を維持する。

手動転記した全14行・写真SHA-256・換算値は
`analysis/native-doom-v43-v44-benchmark.json` に保存。写真本体は配布しない。
