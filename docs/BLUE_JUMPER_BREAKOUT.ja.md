# VCC/GNDジャンパ付き青基板の確認

2026-11-02。ユーザーからUSB-Cメス／オス、2列ヘッダー、VCC/GNDの赤いジャンパを持つ
青い基板の写真を受領。型番・回路図は未確認。まだ通電していない。
従来の2枚の緑基板間を配線する案は一旦保留し、この基板の電源分離を優先確認する。

写真のメスが上・オスが下の向きで、左端が上下ともVCC、右端が上下ともGND。
その各2ピンに赤いジャンパが装着されている。
VCCジャンパがUSB両端の電源経路を開閉する可能性はあるが、表示だけでは確定しない。
単に別のVBUS接点群を短絡する構造や迂回経路の可能性も排除せず、後でコネクター側も確認する。

まず本基板をPC・CM・T3P・他の基板から完全に外す。
右のGNDジャンパは装着したまま、左のVCCジャンパだけを抜き、
露出した上下2本のVCCピン間の抵抗を測る。
OLなら次のコネクター間VBUSの検査へ進む。低抵抗ならジャンパ以外の経路を調べる。
この最初の測定だけで、両端の全VBUSが分離されたと確定しない。

ユーザーの最終訂正：VCCジャンパなしはOL、ジャンパありは0.200Ω。
途中の逆の報告は、この最終回答で置き換える。
測定点がジャンパの2ピン間か、USB両端のVBUS間かは明示されていないため、
これだけでコネクター間の電源分離を確認済みとはしない。
左右に黒いUSB-C取り出し基板を接続した写真も受領した。
次は無通電のまま、その左右のVBUS間をジャンパあり／なしで測り、
GNDジャンパを残した状態で左右のGND間の導通も確認する。

続いてユーザーが「その表の通り」と確認：左右黒基板のVBUS間は
VCCジャンパなしOL／ありほぼ0Ω、GNDジャンパを残した左右GND間はほぼ0Ω。
この測定範囲で電源の開閉とGNDの維持を確認できた。
各コネクターのA4/A9/B4/B9全接点を個別に測った記録ではない。
VCCジャンパを外しGNDジャンパを残した無通電状態で、ユーザーが次を実測した：
左右USB+同士0.200Ω、左右USB−同士0.200Ω、USB+とUSB−の間OL、VBUSとGNDの間OL。
測定点間のデータ導通と短絡がないことを確認。実際のUSB通信はまだ未確認。

中央のD+/D−は上下で表示の位置が逆なので、列が同じという理由で追加短絡しない。
データの導通確認を通過。T3Pへの採用前に、電源OFF時の実電圧とデータ通信を確認する。

次の依頼：VCCジャンパなし、GNDジャンパあり。写真右の黒基板を外し、
青基板の空いたメスへCMのオスを挿す。写真左の黒基板は残す。
CMメスのみPCへ接続し、T3Pは接続せず、DMMをDC電圧にして左黒基板VBUS-GNDを測る。
まだ電源ジャンパを戻さない。抵抗のまま通電測定しない。

追記：ユーザーの組立写真で、青基板につながっているのはCMのBOOT/RST側
（通常USB・PC側）と確認。こちらの「青基板の左がオス／右がメス」という
先の写真案内が誤っていた。左右を根拠にした接続指示は撤回する。
CMのUSB-CM印字側の長いプラグがPIO側、BOOT/RST側の口がPC側という
既知のCM端子位置を基準に組み直す。PC/T3Pへの接続・電圧測定はまだ未確認。

修正後の写真を確認：左からCM、青基板、黒取り出し基板。
CMのBOOT/RST側の口は左端で空き、USB-CM印字側の長いPIOプラグが青基板へ接続。
青基板の上端GNDジャンパあり、下端VCCジャンパなし。T3P・PCは未接続。
この並びでCM左端の口のみPCへ接続し、DMMのDC電圧で右の黒基板VBUS-GNDを測る段階へ進む。

CMをPCへつないだ電源ジャンパOFFのDC電圧として、ユーザーが0.000Vと報告。
最初のOLは0Vとは解釈せず、直流電圧レンジを案内して得た再測定結果。
次はT3Pを外したまま、測定棒を離して青基板下端VCCジャンパを戻し、
GNDジャンパとPC接続を維持して同じ黒基板VBUS-GND間のDC電圧を測るよう依頼した。
ON時にユーザーが5.085Vと報告。OFF時0.000Vと合わせて電源開閉を確認。
CMの読み取り専用状態確認も成功し、v3、frames=0、armed/used/host_requested/fault/bias_activeすべてfalse。
状態記録：local/cm-blue-off-readonly-status.json。

次にPCケーブルを一旦抜き、黒基板VBUS→10kΩ→中点→10kΩ→GNDの分圧を組むよう依頼。
中点はCMへ未接続、T3Pも未接続。VCC/GNDジャンパありでCMをPCへ戻し、
中点-GND間をDC電圧で測る。約2.54Vを見込むが実測待ち。

ユーザーから中点2.522Vの報告を受領。CMの電源検出プログラムを導入し、
GPIO26未接続のまま送信0・ホスト停止・待機解除を確認した。
次はPCを抜いて、中点をCMの26の穴（27と10の間）へ接続しPCへ戻すよう依頼。
VCC/GNDジャンパあり、T3Pなしを維持。まだADCのON/OFF確認はしていない。

続報：ADCのON/OFFとT3Pなしの一回波形試験を経て、実機T3Pを接続した通常USB認識にも成功。
local/cm-power-normal-usb1.jsonでHID0483:5750を確認。今回の青・黒基板列で電源とデータの経路が通る。
この通常USB認識で復旧キーやFlash操作は追加していない。詳細はCM_POWER_PROBE.ja.md。
