# RYKEN RK_M002 V1.5の接続確認

2026-11-02。ユーザーが実物の表裏写真を提示し、電源スイッチの代用を提案。
本基板はまだCM・T3Pへ接続しておらず、導通・通電試験も未実施。

写真で確認できる表示:

| DIP | 表示 |
| --- | --- |
| 1 | D+ |
| 2 | D− |
| 3 | CC1 |
| 4 | CC2 |
| 5 | 5.1K 下拉（プルダウン） |

写真の表側をUSB-Aメスが上、USB-Cオスが下となる向きで見ると、
右上のUSB-CメスがData、右下のUSB-Cメスがpowerと読める。
この表示だけではVBUSの接続は確定できない。
5番を5Vの開閉スイッチとして扱わず、内蔵5.1kΩを既存のGPIO10→D+抵抗の代用にしない。

採用条件は、Data側VBUSが主USB-CオスのVBUSと分離され、GNDとデータ経路は通ること。
Power側から主USB-CオスへVBUS/GNDが通るなら、外部給電ケーブルの挿抜で
データを接続したままT3P側の電源を切り替えられる可能性がある。
現時点ではこの構成は仮説であり、確認前にPCやT3Pへ接続しない。

## 次の無給電検査

PC・CM・T3P・他の電源を外し、DIPをすべてOFFにする。
RYKENの主USB-Cオスへ旧YC269メス取り出し基板を挿し、主端子側のVBUSとGNDを取り出す。
新しいオス・メス取り出し基板を他の配線から独立させ、
そのオスをまずRYKENのData側メスへ挿してVBUS同士・GND同士の抵抗を測る。
次にオスをPower側メスへ移して同じ2組を測る。
新しい取り出し基板のメスは空けたまま。SGNDはGNDの代わりに使わない。

| ポート | 主端子VBUSとの抵抗 | 主端子GNDとの抵抗 |
| --- | --- | --- |
| Data | 0.300Ω、4つのVBUS/VCCの全組合せとユーザー確認 | 未測定 |
| Power | 基板が干渉し未測定 | 未測定 |

OL以外の値もそのまま記録し、低抵抗での直結と、抵抗・保護素子などを介した経路を区別する。
この検査の後でD+/D−の経路、スイッチ設定、USB通信、OFF時の実電圧を確認する。
確認が済むまでは主ポートへ複数の給電元をつながない。

ユーザー報告: Data側は0.300Ω。VBUS同士かGND同士かは確認中。
Power側は取り出し基板同士が物理的に干渉し、直接は装着できない。
延長ケーブルを追加しての測定はまだ依頼していない。
Dataの0.300ΩがVBUS同士であれば、その経路は低抵抗でつながっており、
Data側だけから信号を通して主端子の5Vを独立させるという採用条件を満たさない。
その場合はPower側の追加測定を省き、別の構成へ進める。

ユーザーが「4つあるVBUS/VCC同士、どの組合せでも0.300Ω」と確認。
Data側を用いて主端子のVBUSを分離する案は不採用とし、延長ケーブルを増やす追加測定は不要。
Power側や他の全信号の回路を確定したという意味ではない。
