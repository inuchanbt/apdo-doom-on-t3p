# V49の連続動作試験

2026-11-06。**V49で左ボタンの操作と2分以上の連続動作を実機確認。** この時点の開発基準版をV49とした。現在の操作とビルド手順は [V58のREADME](../README.ja.md) を参照。

V48は固定1 tic／フレームの比較計測で平均145 msを記録した。
V49では同じ描画・DMA転送を使い、実時間に沿ってゲームを進め、既知の左ボタンで発射できる状態に戻す。
通常動作では1回の描画の間に複数のゲームticを処理する。

## 実機結果

ユーザーは、左ボタンの短押しで1発、長押しで連射、AMMOが0になると殴りに切り替わることを確認した。
操作の反応も良く、2分以上動作したとの報告。通常プレイのFPSは未計測。[実機記録](../analysis/native-doom-v49-physical-success.json)

## 変更した点

- 固定ticを外し、ハードウェアのミリ秒時計と通常のエンジンスケジューラーを使う。
- PA11の左／起動ボタンによる発射を有効化。描画中の押下を保持する既存処理も使う。
- 画面上の診断数値、毎フレームの照合計算、40フレーム後の意図的な停止を外す。
- V48の2枚の120×120インデックス画面、固定パレット、2本の16列RGB565転送バッファ、描画中の転送処理を維持。
- 全582ページ無圧縮のゲームデータと初回CRC検証を維持。

描画・MMIO転送コードを含む10個のオブジェクトと、既存エンジンアーカイブはV48とバイト単位で同じ。
CPU／PLL／FlashクロックとDBI分周設定も変更していない。
右ボタン、タッチ、移動・傾き・気圧・音センサーの実機ドライバーはまだ組み込んでいない。

## 実機での確認

1. `artifacts/native-doom-v49/T3P_NATIVE_DOOM_E1M1_V49_3.0.3.bin` を、これまでのHID更新手順で書き込む。
2. 通常起動ではボタンを離す。ゲームとHUDが表示され、診断数値は出ない。
3. 左ボタンの短押しと長押しで発射するか確認する。
4. 1〜2分そのまま動かし、途中でも発射できるか、画面の乱れや停止がないか確認する。

今回のファームは計測終了画面へ移らず、動作を続ける。結果は発射の反応、連続動作、見た目の速度で確認する。
起動時に左ボタンを押したままにすると、従来どおり純正のHID更新画面へ入る。

## 容量と検証

| 項目 | V49 |
|---|---:|
| 更新ファイル | 1,540,096 B |
| 全無圧縮ゲームパック | 1,199,344 B |
| 静的RAM | 113,976 B |
| 予約後のRAM残量 | 54,832 B |
| 予約後のFlash残量 | 55,524 B |

Flashドライバー80 KiB、RAMドライバー32 KiB、スタック16 KiB、下部ROM／IRQと上部512 Bの更新領域の予約を維持。

- PC上の実エンジンを直列版・並行版で各668ステップ実行。1〜200 msの可変時計と通常スケジューラーで進め、
  2,746 ticまで画像・ゲーム状態・弾数が一致。発射で弾数が50→39になり、前進・旋回・メニュー復帰も確認。
- 各666画面を転送完了。転送元を保持したまま遅らせる検査を各39,960回行い、完了した画面を毎ステップ照合。
  描画を省くメニューのループと最後の転送待ちも確認。
- 転送モジュールの336画面試験、実MMIOコードの寸法・完了・タイムアウト試験、Python回帰テスト66件が通過。
- 固定ticモードの回帰試験148ステップも通過し、元の40 ticの画像列 `EBC8D404` を再現。
- ネイティブの逆アセンブルで実時計の呼出しとPA11の読取りを確認。計測用表示・集計関数と解凍関数はリンクされていない。
- 別の展開ツールでapp.binとペイロードの一致、他の44ファイルと2ディレクトリーの純正との一致を確認。
  先頭20 KiB、リソース末尾、入れ子CRC、再復号の一致も検証した。

PCの仮想時計と転送待ちは、実機の速度や長時間安定性の測定ではない。
PCの移動・メニュー試験は入力注入によるもので、実機の移動操作が実装済みという意味ではない。
ソース内の旧称 `T3P_PROFILE_HOT` は無圧縮読取りの初回CRCビットにも使われるため残すが、
無圧縮モードにはページ順位カウンターがなく、その他の計測・ベンチマーク指定は無効にしている。

## 再実行

```powershell
$Pi32 = 'C:/path/to/JL/pi32'
python scripts/build_engine.py --host-test --game-page-bytes 2048 --raw-game-only --present-mode serial --output artifacts/host-present-play-serial
python scripts/build_engine.py --host-test --game-page-bytes 2048 --raw-game-only --present-mode overlap --output artifacts/host-present-play-overlap
python scripts/check_play_pipeline.py
python scripts/check_present.py
python scripts/build_native_board.py --toolchain $Pi32 --doom --package-doom --revision 49
```

これらはPC上の生成・検証だけを行い、デバイスへの書き込みは行わない。
